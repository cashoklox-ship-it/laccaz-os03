# Laccaz OS 0.5 — desktop и Центр приложений

Исходный проект Debian 13 amd64. ISO собирается GitHub Actions; готового ISO в архиве нет.

## Исправление бага окон
В конфигурации Openbox 0.3 отсутствовали mouse bindings для Close, Iconify и Maximize: кнопки отображались, но не выполняли действия. В 0.4 они добавлены, восстановлены изменение размеров за края, фокус окна и меню заголовка. Кнопки стандартных окон перенесены влево, увеличены за счёт новой темы/размера заголовка. В собственных приложениях Laccaz цветные кнопки имеют область нажатия 36×36 px и видимый круг 24 px. Закрытие Dev Hub при выполняемой задаче предлагает остановить её и затем закрывает окно.

## Новые возможности
- Dev Hub: запуск/сборка шаблонов Python, C, C++, JavaScript; последовательность configure/build/run для C++; остановка при ошибке. Stop завершает POSIX-группу процесса, включая дочерние процессы.
- Тесты: pytest для Python, npm test для JavaScript, CTest для C++; тесты нужно добавить в свой проект. Для C готовый запуск тестов не настроен. Шаблоны сами по себе тестов не содержат. Pytest установлен для системного Python; в .venv его нужно установить отдельно.
- Зависимости: requirements.txt в Python venv; npm ci/install для JavaScript. Эти действия могут скачивать пакеты и запускать предусмотренные пакетами install-скрипты. Кнопку используй в своих доверенных проектах.
- Git: статус, diff, история; добавление всех изменений в индекс с подтверждением; коммит только уже добавленных изменений. Push не выполняется. Git identity задаётся самостоятельно.
- Утилиты: форматирование JSON, разбор URL без сетевого запроса, SHA-256 текста, сохранение лога.
- Дополнительные пакеты: clangd, ccache, Meson, pkg-config, strace, Valgrind, pytest, pipx. Они установлены как инструменты; не каждый имеет отдельную графическую панель.
- Док с анимацией иконок; центр управления открывает реальные настройки звука (pavucontrol) и подключений (nm-connection-editor). Встроенных собственных регуляторов громкости/Wi-Fi пока нет.
- Win+Space — приложения; Win+V — буфер; Win+E — файлы; Win+D — показать рабочий стол; Win+Enter — терминал; Alt+Tab — окна. Эти сочетания относятся к сеансу Surface/Openbox, не к Plasma.
- Live-hook выбирает laccaz.desktop после стандартной настройки SDDM. Этот boot-time hook ещё не проверен на загруженном ISO. При необходимости выбери Surface вручную.

## Получить ISO через GitHub
1. Распакуй архив. Загрузи СОДЕРЖИМОЕ папки laccaz-os в корень репозитория, заменив предыдущие файлы. auto, config, scripts и .github должны быть рядом.
2. Обязательно замени .github/workflows/build.yml файлом из этого архива. Если скрытая папка не загрузилась, создай этот файл вручную и вставь содержимое из архива.
3. Actions → Build Laccaz OS 0.5 → Run workflow → main → Run workflow.
4. После успешной сборки скачай artifact laccaz-os-0.5-amd64 и распакуй ZIP. Внутри laccaz-os-0.5-amd64.iso и SHA256SUMS.
5. Сначала проверь Live и установку на пустой диск виртуальной машины. Полный ISO 0.4 в авторской среде не собран и не проверен.

build.sh также восстанавливает исполняемые права на скриптах, потерянные при загрузке через сайт. Настройки KDE копируются из обычного файла при сборке — потеря скрытой .config больше этому не мешает.

## Применить исправление к уже запущенной Laccaz OS
Распакуй архив ВНУТРИ Laccaz OS, открой терминал в папке laccaz-os и выполни:

```bash
sudo bash scripts/update-existing.sh
```

Скрипт сохраняет резервную копию текущей оболочки/конфигурации в /var/backups/laccaz и обновляет файлы интерфейса. Затем выйди из сеанса и войди в Laccaz Surface (X11 Preview). Это не обновляет ядро и не устанавливает новые пакеты. Для дополнительных инструментов:

```bash
sudo apt update
sudo apt install clangd ccache meson pkg-config strace valgrind python3-pytest pipx network-manager-gnome pavucontrol
```

В Live без persistence изменения исчезнут после перезагрузки; для постоянного результата пересобери ISO. Пароль Live по умолчанию — live; при установке используется созданная тобой учётная запись.

## Внешний вид
Нижний док, верхнее меню, кнопки слева, светлая палитра и анимация вдохновлены macOS. Используется свой код и графика. Это не macOS; Apple frameworks, полноценное преломление Liquid Glass и идентичное оформление всех приложений не реализованы. SDDM и сторонние приложения могут выглядеть иначе.

## Проверки
Qt-регрессии: QT_QPA_PLATFORM=offscreen python3 tests/test_regressions.py.
Для настоящих X11-кликов: установи Xvfb, Openbox, xdotool, wmctrl, PySide6 и запусти xvfb-run -a bash scripts/test-x11.sh. Требуются также GCC, G++, CMake, Node.js, npm и Git для тестов проектов.
Список выполненных проверок и ограничений находится в STATUS.md. Фотографии из previews — снимки тестового Qt/X11-сеанса, не загрузившегося ISO.

# Изменения версии 0.5

## Новый рабочий стол
Оформление приближено к присланному образцу: оригинальные пейзажные обои, тонкое верхнее меню, нижний док с анимацией, виджеты календаря и местного времени слева. Кнопка «Обои» выбирает локальное изображение и сохраняет путь в пользовательских настройках. Пейзаж создан встроенной генерацией изображений по описанию каменистого тихоокеанского берега на закате с мостом вдали. Графические панели показывают размытую копию обоев под ними; это не полный эффект преломления Liquid Glass и не размытие окон других приложений.

## Центр приложений
Запуск: кнопка A в доке, «Магазин» в верхнем меню или laccaz-appcenter. Есть подборка из 20 приложений Debian: поиск по названию/описанию/категории, установленные приложения, установка, удаление, запуск. Это ограниченная подборка, не полный каталог всех пакетов Debian и не магазин приложений Apple. Для обновления данных APT используй «Обновить каталог».

Установка и удаление вызывают маленький root-helper через pkexec. Пароль вводится только в системном окне polkit. Пользовательский GUI не запускается от root. Helper принимает только известные действия/пакеты из защищённого каталога, запрещает неожиданные аргументы, запрещает удаление других пакетов по результатам симуляции и установку с удалением пакетов. Установка может добавить зависимости. При конфликте APT или ошибке сети журнал отображается в приложении. Закрыть приложение во время операции с пакетами нельзя, чтобы не прервать её.

В образ добавлены pkexec, polkitd, lxqt-policykit; агент авторизации запускается вместе с Surface. Удаление программ не стирает пользовательские документы. Сторонние Flatpak/Snap/Apple/Windows приложения этот каталог не устанавливает. Захват Wireshark может потребовать отдельной настройки прав.

## Обновление существующей Laccaz OS до 0.5
Перед запуском скрипта обновления установи новые компоненты:

```bash
sudo apt update
sudo apt install pkexec polkitd lxqt-policykit
sudo bash scripts/update-existing.sh
```

Затем выйди и войди в Laccaz Surface. Нужен интернет. Скрипт обновляет центр, каталог, policy и helper вместе с оболочкой. Для Live без persistence обновление и установленные программы могут исчезнуть после перезагрузки. Сам интерфейс не превращает Live-режим в установленную на SSD систему.

## ISO 0.5
Загрузи содержимое папки laccaz-os в корень репозитория. Обязательно обнови .github/workflows/build.yml; теперь workflow называется Build Laccaz OS 0.5, результат artifacts/laccaz-os-0.5-amd64.iso. Раздел с инструкцией 0.4 выше описывает тот же процесс, но имя версии нужно заменить на 0.5. Сначала проверь ISO в VM.

## Ограничения проверки
Поиск/фильтры, чтение dpkg, обработка отказа/успеха транзакции и root-helper проверены тестами без изменения пакетов. Настоящая установка и окно авторизации polkit внутри загруженного ISO пока не проверены. Тестовый backend в тестах не используется в обычном запуске. В новой версии нет обещания побитового или визуального совпадения с macOS 27.
